# РЖД: fullstack-приложение прогноза доходов

## Запуск backend

```powershell
cd backend
pip install -r requirements.txt
python run.py
```

Backend: http://127.0.0.1:8000  
Swagger: http://127.0.0.1:8000/docs

## Запуск frontend

Во втором терминале:

```powershell
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173

## Если npm не поставил Vite

Из корня проекта:

```powershell
.\install-frontend-clean.bat
```

Потом:

```powershell
cd frontend
npm run dev
```

## Что внутри

Все графики получают данные из FastAPI backend. Frontend не читает CSV напрямую.

Страницы:
- Дашборд: объем перевозок, прогноз на текущий год, доходы до 2036, топ-15 маршрутов, кольцевая диаграмма по доходам грузов 2036 без «Остальных грузов».
- Прогноз объемов: общий объем 2018–2036, прогноз по родам грузов, месячная сезонность с выбором года.
- Доходы по грузам: структура доходов по грузам, динамика, рейтинг, вклад изменения, виды перевозок.
- Карта маршрутов: одна OpenStreetMap-карта с маршрутами и точками.
- Что если: расчет сценария на backend, гистограмма с подписями и разными цветами.
